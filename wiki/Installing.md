# Installing

## From the Chrome Web Store (recommended)

1. Open **[Cart Compass on the Chrome Web Store](https://chromewebstore.google.com/detail/idfkjmeajgiodejoclmlmenkgeooiedo)**.
2. Click **Add to Chrome**, then **Add extension**.
3. Pin it so it's one click away: click the puzzle-piece icon in Chrome's toolbar, then the pin next to **Cart Compass**.

Updates install automatically. It works in Chrome, Edge, Brave and other Chromium browsers.

## Manual install (from a release)

Use this if you can't use the Chrome Web Store, or want to try a version before it's in the store.

1. Download `cart-compass-vX.Y.Z.zip` from the [Releases](https://github.com/jkomilanowicz-lab/Cart-Compass/releases) page and unzip it.
2. Open `chrome://extensions` and turn on **Developer mode** (top right).
3. Click **Load unpacked** and select the unzipped folder.

A manual install doesn't update itself. Repeat the steps with a newer release, or click the reload icon on the extension's card after replacing the folder.

> Don't run the store version and a manual install at the same time. They keep separate data and would both show warnings.
